# دوري المنطقة — موقع المسابقات التسع

## رفع الموقع (النسخة المربوطة)
1. افتح مستودع GitHub: `Elwageh27/league-management-2027`.
2. ارفع واستبدل الملفات التالية في جذر المستودع: `index.html` و`app.js` و`style.css` ومجلد `assets`.
3. **مهم جدًا: لا تحذف ولا تستبدل مجلد `data`**؛ بداخله بيانات المسابقات التسع والأخبار.
4. من Settings > Pages تأكد أن النشر من `main` ومجلد `/(root)`.
5. افتح الموقع: https://elwageh27.github.io/league-management-2027/

## لوحة الإدارة
رابط Apps Script الجديد تم وضعه بالفعل داخل `app.js`. لا تحتاج إلى تعديله يدويًا.

## مهم: نشر الموقع الجديد بدون المساس بالموقع القديم
- أنشئ مستودع GitHub جديدًا باسم مثل `league-management-2027-site`.
- ارفع ملفات هذا الموقع إلى المستودع الجديد فقط.
- لا تعدّل أو تحذف أي ملف في مستودع `league-management-2027`؛ هذا المستودع سيظل مصدر بيانات المسابقات.
- الموقع الجديد يقرأ ملفات البيانات من المستودع الحالي `league-management-2027`، بينما Apps Script يستمر في نشر التحديثات إليه.


## تحديث مباشر للبيانات (إصدار Live API)
1. استبدل محتوى Code.gs بالكامل بمحتوى ملف Apps_Script_Live_Data_API.txt واحفظه.
2. من Deploy اختر Manage deployments ثم Edit (علامة القلم) للنشر الحالي، واختر New version ثم Deploy. لا تنشئ رابطًا جديدًا؛ سيظل رابط /exec نفسه.
3. ارفع ملفات الموقع الجديدة إلى مستودع الموقع فقط. لا ترفع أو تستبدل مجلد data في مستودع البيانات، ولا تلمس الموقع القديم.
4. الموقع الآن يقرأ النتائج والأخبار مباشرة من Apps Script؛ نشر ملفات JSON إلى GitHub لم يعد جزءًا من كل تعديل يومي. يمكن تشغيل publishAllLeaguesNow يدويًا عند الحاجة لتحديث نسخة البيانات الاحتياطية في GitHub.
